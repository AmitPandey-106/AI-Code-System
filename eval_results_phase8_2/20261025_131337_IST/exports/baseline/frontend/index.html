LITE-Coder Research Architecture

Autonomous Self-Healing Architecture

LITE-Coder is a continual-learning coding system that integrates a causal language model with multi-attempt execution feedback, AST security validation, vector memory retrieval, and reinforcement-learning-guided repair selection.

Core Architectural Modules:

  • Base Model: Qwen 2.5 Coder 1.5B with low-rank adaptation (LoRA).
  • Memory Index: FAISS L2 index with Sentence-Transformers (384-dimensional embeddings) storing historical successful repair patterns.
  • Strategy Selector: Multi-armed bandit with ε-greedy exploration choosing among Direct Repair, Test-Guided Repair, and Decomposed Repair.
  • Security Isolation: Python AST parsing disallowing unauthorized file system, subprocess, and network calls before execution.
  • Sandboxed Runner: Isolated subprocess execution environment with strict timeout enforcement.
